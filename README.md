# ECHO: shared campus stories

**DECO3500 · Social and Mobile Computing · The University of Queensland · 2026**

**Team: Inshallah and Vibes: Itisha, Keerthana, Ishan and Inseo (Alex)**

ECHO aims to help students learn about UQ’s history and feel more connected to campus. We designed a book-like installation where students can find stories about a place and leave their own memories. In the digital garden, each person has a tree, and their contributions appear as flowers. Visitors can reply to stories and talk to someone at another installation.

Our [secondary research](https://github.com/Inseo-Park/DECO3500_Inshallah-and-Vibes/tree/main/docs/Secondary%20Research) explores student belonging, campus heritage and connection to place. Our interviews and testing helped us change the garden’s layout, how people find their contributions and how the two locations connect. This repository contains the current prototype, earlier builds and the work behind those decisions. The latest build still needs user testing.

## Run the prototype

1. Clone this GitHub repository to your computer.
2. Open the `prototype` folder, then double-click `index.html` to open it in your browser.
3. The page displays two installations: **The UQ Lakes** and **The Great Court**. Click whichever location you want to try.
4. In that location's folder (`ECHO-lakes` or `ECHO-court`), click `index.html` to open the prototype for that location.

No installation or terminal commands are needed. If choosing a location opens its prototype directly, you can skip the last step.

Create an ECHO ID, or choose **Show me a full profile** to try the example `LAKEWALKER-07` profile. No account or password is needed.

For optional live linking between two devices and further usage details, see the [prototype guide](docs/prototype-guide.md).
