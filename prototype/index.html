Open this on the other device

To link two devices, one of them has to run the relay first. On a laptop, double-click start-link.command (Mac) or start-link.bat (Windows) in this folder. It prints an address.

Open that address in a browser on both devices — a second laptop, or an iPad — choosing a different installation on each. Anything opened from the relay joins the link by itself; there is no code to type. Both devices need to be on the same wi-fi.

Each installation also works on its own, offline, with nothing running.
