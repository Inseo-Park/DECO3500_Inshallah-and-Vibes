# ECHO questionnaire

This folder contains the questionnaire, its questions in text form and five design images.

- [Open the questionnaire source](index.html)
- [Read the questions](QUESTIONS-to-paste.md)
- [View the images](images/)

## Run it

Download or clone the repository, then open `index.html` in a browser. No server or internet connection is needed. Keep the `images/` folder beside the HTML file so question 4 displays its pictures.

On first use, enter the name or initials of the person collecting responses. This is saved with each response in the CSV. You can change it from the results screen.

Responses stay in that browser on that device. They do not sync with other devices or browsers. Clearing browser data removes them, and private browsing may lose them when the window closes. Export the responses after each session.

## Export responses

Open the results screen using one of these methods:

- Add `#results` to the end of the page address and press Enter.
- Press **Ctrl+Shift+D** on Windows or **Cmd+Shift+D** on macOS.
- Tap the middle of the screen’s top edge three times.

Choose **Download CSV** to save the responses. Each collector should export their own file. To combine files, keep one header row and place the response rows underneath it. The `collector` column shows who collected each response.

## Use another survey tool

Copy the questions from [QUESTIONS-to-paste.md](QUESTIONS-to-paste.md) into Google Forms or Qualtrics. The file includes options, required-field notes and an explanation of what each question measures. Add the five images from `images/` to question 4.
