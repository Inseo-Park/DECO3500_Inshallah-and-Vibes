# ECHO questionnaire

This questionnaire explores where students spend time on campus, which ECHO designs they prefer, and whether they would discover or share stories.

- [Questionnaire](index.html)
- [Questions in text form](QUESTIONS-to-paste.md)
- [Design images](images/)

Download the folder and open `index.html` in a browser. Keep the `images/` folder beside it so the design images display.

Responses are saved in the browser on that device. After each session, add `#results` to the page address and select **Download CSV** to save a copy.
