# Book-opening concepts

For teaching staff: the images in this folder show potential methods for opening the ECHO book that the team discussed during design exploration:

- [Piece together](piece-together.png)
- [Simon Says](simon-says-uq-echo.png)

These ideas were not used in the final prototype. We chose a simple approach: when someone comes close to the book, a proximity sensor detects them and triggers the book to open automatically, revealing the screen inside.
