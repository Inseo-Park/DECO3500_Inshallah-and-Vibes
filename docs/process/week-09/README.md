The later overview covers the Social Garden, Arduino interaction and final showcase. `wiki/ECHO_Design_Process_Overview_UPDATED.md` contains the same overview with raw GitHub image URLs for copying to the Wiki; `wiki/Design-Process-Overview.md` is an earlier version.

For the current build and setup steps, see [echo-tradeshow](../../../prototype/index.html) and the [prototype guide](../../prototype-guide.md).

The wiki pages are grouped in `wiki/`. Their supporting images remain in the Week 9 folder and `images/`. Identical images from the former archived wiki package use the existing copies in `images/`.

The links work from this folder. If you copy these pages to a GitHub Wiki, update the links so they point to the repository files.

Image filenames describe their contents. The feedback sheets are numbered by their printed page order. Duplicate image copies are documented in the image audit and retained for review.
