ECHO – Thematic Analysis Board

Inductive coding of 6 interview transcripts. Each sticky note = one code, with a short quote and the delivery/emotion read from how it was said (hedges, fillers, repetition, humour, tone words).

Method: familiarisation → open coding of quotes → grouping codes into themes → naming themes and design insights. Caveat: delivery and emotion are inferred from transcript text only (no audio), so treat them as interpretations. Two interviews appear to describe another university (one mentions QUT and says it is “not as old as UQ”), so use them as comparative evidence, not UQ-specific. Small, qualitative sample, so themes are indicative, not generalisable.
